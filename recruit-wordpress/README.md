# WordPress 固定ページ貼り付け用（ファイルのアップロード不要）

**このフォルダのファイルは、WordPress の管理画面にコピペするだけで採用ページになります。**
FTPもファイルのアップロードも不要です。

> **なぜこの形式なのか**
> WordPress のメディアライブラリは、セキュリティ上 `.html` `.css` `.zip` を受け付けません。
> そのため `recruit/` フォルダの HTML ファイルをそのまま上げることができません。
> このフォルダは、CSSを内側に埋め込み、貼るだけで完成する形に変換したものです。
> **生成物なので直接編集しないでください。** 直すのは `recruit/` 側です（第6節）。

---

## 1. 作る固定ページ（5ページ）

| 貼り付けるファイル | ページタイトル | スラッグ | 親ページ |
|---|---|---|---|
| `index.html` | 採用情報 | `recruit` | なし |
| `koushi.html` | 個別指導講師（アルバイト・パート） | `koushi` | 採用情報 |
| `koushi-chuju.html` | 個別指導講師（中学受験） | `koushi-chuju` | 採用情報 |
| `koushi-kokosei.html` | 個別指導講師（高校生・英語／数学） | `koushi-kokosei` | 採用情報 |
| `jimu.html` | 教室運営・事務スタッフ（パート） | `jimu` | 採用情報 |

**ページタイトルは必ずこのとおりにしてください。** テーマがページタイトルを見出し（h1）として出力し、
それが検索結果に出る求人名になります。

親子関係を設定すると、URLが `https://www.musasinokobetu.com/recruit/koushi/` の形になります。
ページ内のリンクはこの形式で書いてあるので、**親子設定を忘れるとリンクが全部切れます。**

## 2. 手順

### ステップ0：パーマリンク設定を確認する（最初に1回だけ）

「設定」→「パーマリンク」を開き、**「基本」以外**が選ばれていることを確認してください。
「基本」だとURLが `?page_id=123` の形になり、`/recruit/koushi/` になりません。

「投稿名」が選ばれていれば問題ありません。

> **既存サイトのパーマリンク設定は変更しないでください。**
> すでに「基本」以外なら、そのままで大丈夫です。もし「基本」だった場合、変更すると
> 既存ページのURLが全て変わってしまいます。その場合は変更せず、ご相談ください。

### ステップ1：親ページ「採用情報」を作る

1. 「固定ページ」→「新規追加」
2. タイトルに **採用情報** と入力
3. 本文エリアで **「+」ボタン →「カスタムHTML」ブロック**を追加
   （検索窓に「カスタム」と打つと出てきます）
4. `index.html` の中身を **全部** コピーして、そのブロックに貼り付ける
5. 右側の「固定ページ」タブ →「URL」→ スラッグを `recruit` にする
6. 「公開」

### ステップ2：残り4ページを作る

同じ手順で、表のとおりに4ページ作ります。ステップ1との違いは2点だけです。

- 右側の「固定ページ」タブ →「ページ属性」→ **「親ページ」に「採用情報」を選ぶ**
- スラッグを表のとおりにする

### ステップ3：表示を確認する

`https://www.musasinokobetu.com/recruit/` を開いて、次を確認してください。

- [ ] 4つの求人カードが表示されている
- [ ] 各カードのリンクをクリックして、それぞれの求人ページに飛ぶ
- [ ] 各求人ページの「他の職種を見る」で採用トップに戻れる
- [ ] スマホで見て、表が横にはみ出していない
- [ ] サイトのデザイン（ヘッダー・フッター）が崩れていない

### ステップ4：構造化データが出ているか確認する（重要）

**ここが通らないと Google しごと検索に載りません。**

1. [リッチリザルトテスト](https://search.google.com/test/rich-results)を開く
2. 求人ページのURL（例：`https://www.musasinokobetu.com/recruit/koushi/`）を入れて実行
3. **「求人情報」が検出されればOK**です

**検出されない場合**は、WordPress が `<script>` タグを削除しています。第4節を見てください。

### ステップ5：メニューに追加する

「外観」→「メニュー」で、「採用情報」ページをメニューに追加してください。
サイト内からリンクされていると、Google のクロールが早くなります。

### ステップ6：Google に登録する

1. [Google Search Console](https://search.google.com/search-console) で `musasinokobetu.com` を登録
2. SEOプラグイン（Yoast、All in One SEO、SEO SIMPLE PACK など）が入っていれば、
   サイトマップは自動生成されています。そのURLを Search Console に送信してください
   （多くの場合 `https://www.musasinokobetu.com/sitemap.xml` または `/wp-sitemap.xml`）
3. `recruit/sitemap.xml` は**この方式では不要です**（WordPressが自動生成するため）

掲載までは通常、数日から2週間程度です。

## 3. 貼り付け前に必ず直すこと

**給与は確定済みです。** 全職種とも時給1,400円（授業は1コマ90分＝2,100円）。
授業前後の準備・報告・添削・研修の時間にも同じ時給1,400円を支給する形で書いてあります。

残っているのは次の2点だけです。

| ファイル | 直す箇所 |
|---|---|
| 全ファイル | 交通費（1日1,000円で仮置き）／給与支払日（当月末締め・翌月15日払いで仮置き） |
| `jimu.html` | 月謝・請求業務を事務スタッフの担当範囲に含めるか |

金額を変える場合は、**ファイル内の2か所を両方直してください。**

1. 本文の「募集要項」の表に出る金額（人が読む部分）
2. ファイル末尾の `"baseSalary"` の中の数字（Googleが読む部分）

片方だけ直すと、検索結果に出る金額と実際のページの金額が食い違います。

また、`"datePosted"` を公開日に、`"validThrough"` を掲載終了予定日にしてください。
**`validThrough` を過ぎると掲載が止まります。**

## 4. `<script>` が消えてしまう場合

リッチリザルトテストで「求人情報」が検出されない場合、WordPress または
セキュリティプラグインが `<script type="application/ld+json">` を削除しています。

原因と対処は次のとおりです。

### 原因1：投稿者の権限が足りない

固定ページを作ったユーザーが「管理者」でない場合、`<script>` は自動で削除されます。
**管理者アカウントで作り直してください。**

### 原因2：セキュリティプラグインが削除している

Wordfence、SiteGuard、iThemes Security などが `<script>` を除去することがあります。
プラグインの設定で許可するか、次の方法に切り替えてください。

### 対処：プラグインで構造化データを入れる

1. プラグイン「WPCode」（旧 Insert Headers and Footers）をインストール・有効化
2. 「Code Snippets」→「Add Snippet」→「Add Your Custom Code」
3. Code Type に **HTML Snippet** を選ぶ
4. 各ファイルの末尾にある `<script type="application/ld+json">` から `</script>` までを貼る
5. 「Insertion」で **Site Wide Header** ではなく、
   「Page Specific」→ 対象の固定ページだけを指定する
6. 保存して有効化

この場合、固定ページ側に貼るHTMLからは `<script>` ブロックを削除してください
（同じ構造化データが2回出ると、Googleが混乱します）。

**求人1件につきスニペット1つ**です。ページと構造化データの組み合わせを間違えないでください。

## 5. 注意点

### 本文とJSON-LDの内容は一致させる

Google は「ページに書いてあること」と「構造化データ」が食い違う求人の掲載を止めます。
条件を変えるときは、必ず両方を直してください。

### 募集が終わったら消す

募集していない求人を出し続けると、応募者にも Google にも不利益です。
募集終了時は、**固定ページを下書きに戻すか削除**してください。
`validThrough` を過去日にするだけでも掲載は止まります。

### デザインの干渉について

このファイルのCSSは全て `.mk-recruit` の内側だけに効くよう限定してあります。
サイトの他のページのデザインに影響することはありません。

逆に、テーマ側のCSSが強い場合、採用ページの見た目が一部変わることがあります。
崩れが気になる場合は、どのように崩れているか教えてください。調整します。

## 6. 内容を直したいとき

**このフォルダのファイルを直接編集しないでください。** 次回の生成で上書きされます。

1. `recruit/` 側の該当ファイルを直す
2. `python3 recruit/build_wordpress.py` を実行する
3. `recruit-wordpress/` に新しいファイルが生成される
4. WordPress の該当ページのカスタムHTMLブロックを、新しい中身で置き換える

検査は次のコマンドで行います。

```bash
python3 recruit/check_jobposting.py                                    # 元ファイル
python3 recruit/check_jobposting.py --fragment recruit-wordpress/*.html # 貼り付け用
```

## 7. FTP が使える場合はそちらが簡単です

WordPress が動いているレンタルサーバーの**ファイルマネージャーやFTP**が使えるなら、
`recruit/` フォルダの7ファイルを公開ディレクトリ直下の `/recruit/` に置くほうが簡単です
（固定ページを5つ作る必要がありません）。

サーバーの管理画面に「ファイルマネージャー」「WebFTP」といった項目がないか探してみてください。
その場合の手順は `recruit/README.md` の第2節Aにあります。

ただし、**`recruit` という名前の固定ページ・投稿・カテゴリが存在すると衝突します。**
この方式を採る場合は、固定ページのほうは作らないでください。

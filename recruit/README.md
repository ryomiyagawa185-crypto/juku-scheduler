# 自社採用ページ（Google しごと検索 対応）

**このリポジトリだけで完結する唯一の無料求人経路です。**

求人媒体は全て、企業アカウントの開設に事業所確認（電話番号認証・事業所番号・法人確認）を要求します。
一方、**Google しごと検索（Google for Jobs）にはアカウント登録が存在しません**。
自社サイトのページに `JobPosting` 構造化データを置けば、Google がクロールして無料で掲載します。

このフォルダは、その採用ページ一式です。GitHub Pages で公開されれば、それだけで求人が世に出ます。

## 1. ファイル構成

```
recruit/
├── README.md               ← このファイル
├── index.html              ← 採用トップ（求人一覧・塾の紹介）
├── koushi.html             ← 個別指導講師（アルバイト・パート）
├── koushi-chuju.html       ← 個別指導講師（中学受験）
├── koushi-kokosei.html     ← 個別指導講師（高校生・英語／数学）
├── jimu.html               ← 教室運営・事務スタッフ（パート）
├── kyoshitsucho.html       ← 教室長候補（正社員）
├── style.css               ← 共通スタイル（外部リソース依存なし）
├── sitemap.xml             ← Search Console 送信用
└── check_jobposting.py     ← 構造化データの検査スクリプト
```

1求人1ページの構成です。Google しごと検索は「1ページに1求人」を前提としているため、
一覧ページ（index.html）には JobPosting を置かず、Organization のみにしています。

## 2. 公開までの手順

### ステップ1：`【要確認】` を実額に置き換える

各 HTML の先頭にある HTML コメントに、確定が必要な項目を書いてあります。

| ファイル | 確定が必要な項目 |
|---|---|
| `koushi.html` | 1コマ単価（2,000〜2,800円）／事務給（1,267円）／交通費 |
| `koushi-chuju.html` | 1コマ単価（2,400〜3,500円）／事務給／交通費 |
| `koushi-kokosei.html` | 1コマ単価（2,200〜3,000円）／事務給／交通費 |
| `jimu.html` | 時給（1,250〜1,450円）／交通費／月謝業務を含めるか |
| `kyoshitsucho.html` | 月給レンジ／賞与・昇給実績／年間休日／時間外の月平均／**固定残業代の有無** |

**金額は本文の表と JSON-LD の `baseSalary` の2か所にあります。両方直してください。**
片方だけ直すと、検索結果の表示と実際のページで金額が食い違います。

### ステップ2：日付を更新する

各ページの JSON-LD にある `datePosted` を公開日に、`validThrough` を掲載終了予定日にします。
現在は `datePosted: 2026-08-02` / `validThrough: 2026-10-31` です。

**`validThrough` を過ぎると掲載が止まります。** 期限が来る前に更新するか、募集終了ならページごと削除してください。

### ステップ3：検査を通す

```bash
python3 recruit/check_jobposting.py
```

必須項目の欠落、住所の不足、期限切れ、identifier の重複、`【要確認】` の残りを検出します。
期限は本日基準で判定し、残り14日以内になると警告します。
（`--date 2026-12-01` のように基準日を指定して先の状態を確認することもできます。）

### ステップ4：main にマージして公開

このブランチをマージすると GitHub Pages に反映されます。
公開URL：`https://ryomiyagawa185-crypto.github.io/juku-scheduler/recruit/`

> **マージするまでは公開されません。** PR は draft で、求人はまだ世に出ていません。

### ステップ5：Google に登録する

1. [Google Search Console](https://search.google.com/search-console) でサイトを登録（所有権確認）
2. 「サイトマップ」から `recruit/sitemap.xml` の URL を送信
3. [リッチリザルトテスト](https://search.google.com/test/rich-results)に各求人ページの URL を入れ、
   「求人情報」として認識されるか確認する
4. インデックス後、Google で「武蔵境 塾講師 求人」等を検索して掲載を確認

掲載までは通常、数日から2週間程度かかります。

## 3. 本来は自社ドメインに置くべきです

現在の公開先は GitHub Pages のサブドメインです。求人としては動きますが、
**`musasinokobetu.com/recruit/` に置いたほうが有利**です。理由は3つあります。

- 求職者が「塾の公式サイトの採用ページ」だと一目で分かる
- 既存サイトの評価を引き継げる（新規ドメインより早くインデックスされる）
- Indeed・求人ボックス・スタンバイが自社採用ページをクロールする際、公式ドメインのほうが扱いが良い

このフォルダは外部リソースに一切依存していない（CDN・外部フォント・外部画像なし）ので、
**フォルダごとコピーするだけで移せます。** 移設時は各ファイルの以下を書き換えてください。

- `<link rel="canonical">` の URL
- `sitemap.xml` の全 `<loc>`

## 4. 他媒体への波及

この採用ページは、他の無料媒体への入口にもなります。

| 媒体 | 自社採用ページとの関係 |
|---|---|
| Google しごと検索 | **アカウント不要。構造化データだけで掲載される**（このページの主目的） |
| 求人ボックス | 自社サイトのクロール掲載あり。掲載申請が必要な場合があります【要確認】 |
| スタンバイ | 同上【要確認】 |
| Indeed | 企業アカウントで自社サイトを登録するとクロール対象になります |
| engage / Airワーク | 別途アカウント開設が必要（このページとは独立） |

各社のクロール掲載の条件は変わることがあるので、掲載申請の要否は各社の最新情報で確認してください。

## 6. 応募導線について

現在の応募導線は**電話のみ**です（`tel:` リンク）。

メールアドレスまたは応募フォームを用意すると応募率が上がります。GitHub Pages は静的ホスティングで
フォームの受信ができないため、追加するなら次のいずれかです。

1. **メールリンク**（最も簡単）— `mailto:` を追加する。受信用アドレスの用意だけで済みます
2. **Google フォーム** — フォームを作り、応募ボタンのリンク先にする。無料で、応募内容がスプレッドシートに溜まります
3. **外部フォームサービス** — 送信先が外部になるため、個人情報の取り扱いの確認が必要です

**2 を推奨します。** 応募者の連絡先・希望曜日・指導可能科目を最初から構造化して受け取れるので、
折り返しの電話が1回で済みます。フォームを作っていただければ、リンクの組み込みは対応します。

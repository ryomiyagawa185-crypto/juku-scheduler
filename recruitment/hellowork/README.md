# ハローワーク版 求人申込書（求人者マイページ入力用）

ハローワークインターネットサービスの **求人者マイページ**にそのまま入力できる形で、
求人申込書の全項目を用意しています。

---

## 1. ファイル一覧

```
hellowork/
├── README.md                        ← このファイル（投稿手順・入力規則）
├── check_limits.py                  ← 文字数制限の自動チェックスクリプト
├── 00_事業所情報_共通.md              ← 事業所登録シート（初回のみ・全求人共通）
├── 01_教室長候補_正社員.md            ← ⛔ 募集なし（保管）
├── 02_個別指導講師_パート.md          ← パート求人（本命）
├── 03_教室運営事務スタッフ_パート.md   ← パート求人
└── 04_個別指導講師_中学受験_パート.md  ← パート求人（経験者向け・任意）
```

## 2. 投稿手順

### ステップ0：事業所登録（初回のみ）

求人者マイページを持っていない場合、先に事業所登録が必要です。

1. ハローワークインターネットサービス → 「事業所情報・求人情報の仮登録」
2. `00_事業所情報_共通.md` の内容を入力して仮登録
3. **管轄のハローワークで内容確認を受ける**（窓口またはオンライン）
   - 武蔵野市の管轄は **ハローワーク三鷹**
     〒181-8517 三鷹市下連雀4-15-18／TEL 0422-47-8609
     （三鷹市・武蔵野市・西東京市・東久留米市・清瀬市を管轄）
   - 初回は事業所の実在確認のため、窓口での手続きを求められる場合があります
4. 事業所番号とマイページのアカウントが発行される

すでに事業所番号をお持ちの場合はステップ1へ。

### ステップ1：求人の仮登録

1. 求人者マイページにログイン → 「新規求人情報を登録」
2. 求人区分を選択
   - `02` `03` `04` → **一般求人／パート**
   - ※ `01_教室長候補` は募集していません。仮登録しないでください
3. 各ファイルの表の「入力内容」列を、対応する入力欄にコピペ
4. 「求人情報を公開する範囲」を選択（推奨：**4. 事業所名等を含む求人情報を公開する**）
   - 公開範囲を狭めると応募が大きく減ります
5. 仮登録を完了する

### ステップ2：ハローワークの確認 → 公開

- 仮登録後、管轄ハローワークが内容を確認します（通常1〜3営業日）
- 修正依頼が入ることがあります（賃金の内訳、変更の範囲の記載など）
- 受理されると公開されます

### ステップ3：有効期間の管理

- 求人の有効期間は **受理日の属する月の翌々月末まで**（実質2か月弱）
- 期限が切れると自動的に非公開になります。**継続する場合は期限前に更新操作が必要**です
- カレンダーに「求人の更新」を登録しておいてください

## 3. 重要：Indeed との重複に注意

**ハローワークの求人は Indeed に自動転載されます。**
すでに Indeed へ直接投稿している職種と同じ内容がハローワーク経由でも載ると、
同一求人の重複として Indeed 側で表示順が下がることがあります。

推奨する運用：

| 職種 | Indeed 直接投稿 | ハローワーク |
|---|---|---|
| ~~教室長候補（正社員）~~ | ⛔ 募集なし | ⛔ 募集なし |
| 個別指導講師（社会人・主婦(夫)向け） | 停止する | ◯ 出す |
| 教室運営事務スタッフ | 停止する | ◯ 出す |
| 個別指導講師（大学生アルバイト） | ◯ 出す | 出さない（学生の利用が少ない） |
| 個別指導講師（高校生・英数） | ◯ 出す | 出さない |
| 講習期間限定（短期） | ◯ 出す | 出さない（有効期間と合わない） |
| オンライン（在宅） | ◯ 出す | 出さない |

つまり **社会人向けはハローワーク、学生向けは Indeed** に寄せる形です。

## 4. 入力欄の文字数制限（ハローワーク求人申込書）

| 入力欄 | 制限 |
|---|---|
| 職種 | 全角28文字 |
| 仕事内容 | 全角30文字 × 9行（270文字） |
| 事業内容 | 全角30文字 × 3行（90文字） |
| 会社の特長 | 全角30文字 × 3行（90文字） |
| 就業時間に関する特記事項 | 全角30文字 × 3行 |
| その他の手当等付記事項 | 全角30文字 × 3行 |
| 選考に関する特記事項 | 全角30文字 × 3行 |
| 求人に関する特記事項 | 全角30文字 × 20行（600文字） |

各ファイル内の該当ブロックは、この制限に収まるよう調整済みです。
文言を書き換えたら、以下で再チェックしてください。

```bash
python3 recruitment/hellowork/check_limits.py
```

## 5. ハローワーク特有の注意点

| # | 項目 | 内容 |
|---|---|---|
| 1 | 年齢制限 | 原則禁止。例外事由（長期勤続によるキャリア形成＝3号イ 等）に該当する場合のみ、理由の記載が必要 |
| 2 | 性別 | 限定不可。「主婦」ではなく「主婦（夫）」と記載 |
| 3 | 賃金 | 下限・上限の両方を記載。下限は東京都最低賃金以上 |
| 4 | 固定残業代 | 採用する場合、名称・金額・相当時間数・超過分の別途支給を必ず記載。未記載だと差し戻し |
| 5 | 変更の範囲 | 「就業場所の変更の範囲」「従事すべき業務の変更の範囲」の記載が必須（2024年4月〜） |
| 6 | 有期契約 | 契約期間・更新の有無・更新の判断基準・通算契約期間の上限の記載が必須 |
| 7 | 試用期間 | 期間中の労働条件が異なる場合、その内容の記載が必須 |
| 8 | 受動喫煙対策 | 必須項目。当塾は「屋内禁煙」 |
| 9 | 応募方法 | ハローワークの紹介状が必要かどうかを明示 |
| 10 | 求人票と実際の労働条件の相違 | 相違があると申告対象になります。掲載内容は必ず実態に合わせてください |

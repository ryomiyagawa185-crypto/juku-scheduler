# 武蔵野個別指導塾 採用（無料求人サイト）運用フォルダ

無料で掲載できる求人媒体向けの求人票原稿を管理するフォルダです。

> **自社採用ページは `/recruit/` にあります。**
> Google しごと検索はアカウント登録が不要で、自社ページの構造化データだけで無料掲載されます。
> このリポジトリだけで公開まで完結する唯一の経路です。詳細は `recruit/README.md`。
> 各媒体への投稿は、いずれも事業所確認を伴う企業アカウントが必要です。

## 2. 使い方（Indeed への掲載手順）

1. Indeed の「求人を掲載」→ 無料掲載を選択（有料スポンサー設定はオフのまま）
2. 各ファイルの **「▼ Indeed 入力フォーム対応表」** の項目を、そのまま各入力欄にコピペ
3. 「仕事内容」欄には **`## 仕事内容（本文コピペ用）` 以下を全文貼り付け**
4. 掲載前に `【要確認】` タグが残っていないか全文検索する（残っていたら掲載しない）

> 1求人＝1職種＝1勤務地。複数職種をまとめて1件に投稿すると Indeed 側で非掲載になります。
> 同時掲載は「異なる職種として」別々に投稿してください（同一内容の重複投稿は不可）。

## 3. 掲載前チェックリスト（全求人共通）

| # | 項目 | 根拠 |
|---|---|---|
| 1 | 職種名に「急募」「★」「高時給」等の装飾語・記号を入れていないか | Indeed 掲載ガイドライン |
| 2 | 給与を「応相談」だけにしていないか（下限額は必ず明記） | Indeed 掲載ガイドライン |
| 3 | 年齢・性別を条件にしていないか（「主婦歓迎」→「主婦（夫）歓迎」等の表現に） | 雇用対策法10条・均等法5条 |
| 4 | 「大学生歓迎」等の表現は歓迎条件であって応募資格の限定になっていないか | 同上 |
| 5 | 時給が東京都最低賃金以上か（`【要確認】` 参照） | 最低賃金法 |
| 6 | 授業以外の業務（準備・報告・研修・清掃）にも賃金が発生する設計か | 労基法24条 |
| 7 | 「就業場所の変更の範囲」「業務の変更の範囲」を明示しているか | 2024年4月改正 労基則5条 |
| 8 | 有期契約の場合、契約期間・更新の有無・更新上限を明示しているか | 同上 |
| 9 | 固定残業代を使う場合、時間数・金額・超過分別途支給を明記しているか | 職安法5条の3 |
| 10 | 社会保険・雇用保険の加入条件を書いているか | 職安法5条の3 |
